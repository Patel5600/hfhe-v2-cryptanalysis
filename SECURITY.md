# Security Policy

## Scope

This repository contains **cryptanalytic research** targeting the public HFHE v2 challenge
artifacts. It does not contain production code.

## Reporting vulnerabilities found in this investigation

If you discover an additional attack vector against HFHE v2 that is not documented here,
please open a GitHub issue or contact the repository maintainer directly.

If you find a security problem in the **scripts themselves** (e.g., a bug that invalidates
a negative result), please open an issue titled `[METHODOLOGY BUG]` so results can be
re-validated.

## Responsible disclosure

Any novel cryptanalytic finding against the Octra Labs production system should be
disclosed directly to Octra Labs before public release, following standard responsible
disclosure practices (90-day window).

## Contact

Open a GitHub issue or email the maintainer via the GitHub profile.
